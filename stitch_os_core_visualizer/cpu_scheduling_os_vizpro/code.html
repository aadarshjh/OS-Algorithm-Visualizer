school Shortest Job First (SJF) Preemptive

Also known as Shortest Remaining Time First (SRTF). The scheduler continually evaluates the ready queue and selects the process with the smallest estimated burst time remaining. If a new process arrives with a shorter burst time than what is currently executing, the current process is preempted.
